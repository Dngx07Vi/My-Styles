# STREET//TAG — HipHop Jacket Store

## Chạy web
Mở `index.html` bằng trình duyệt.

## Tính năng
- 6 mẫu jacket ban đầu.
- Tìm kiếm sản phẩm.
- Sắp xếp theo giá/tên.
- Xem chi tiết sản phẩm.
- Thêm sản phẩm.
- Xoá sản phẩm.
- Khôi phục 6 sản phẩm gốc.
- Dữ liệu sản phẩm được lưu bằng `localStorage`, nên reload trang vẫn giữ thay đổi.

## Cấu trúc
- `index.html` — giao diện
- `style.css` — giao diện responsive
- `script.js` — logic sản phẩm
- `assets/` — hình ảnh lookbook đã tạo

Đây là bản frontend thuần HTML/CSS/JS, chưa có database/backend.
